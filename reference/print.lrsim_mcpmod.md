# Print Simulation Results for MCPMod Design for Log-Rank Test

Prints the summary statistics from simulation for MCPMod design.

## Usage

``` r
# S3 method for class 'lrsim_mcpmod'
print(x, ...)
```

## Arguments

- x:

  The lrsim_mcpmod object to print.

- ...:

  Ensures that all arguments starting from "..." are named.

## Value

A tabular printout of the summary statistics from simulation runs.
