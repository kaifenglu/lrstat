# Print Simulation Results for Phase 2/3 Seamless Design for Risk Difference

Prints the summary statistics from simulation for risk difference.

## Usage

``` r
# S3 method for class 'rdsim_seamless'
print(x, ...)
```

## Arguments

- x:

  The rdsim_seamless object to print.

- ...:

  Ensures that all arguments starting from "..." are named.

## Value

A tabular printout of the summary statistics from simulation runs.
