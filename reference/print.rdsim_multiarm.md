# Print Simulation Results for Multi-Arm Multi-Stage Design for Risk Difference

Prints the summary statistics from risk-difference simulation.

## Usage

``` r
# S3 method for class 'rdsim_multiarm'
print(x, ...)
```

## Arguments

- x:

  The rdsim_multiarm object to print.

- ...:

  Ensures that all arguments starting from "..." are named.

## Value

A tabular printout of the summary statistics from simulation runs.
